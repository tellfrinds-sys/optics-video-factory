# مصنع فيديوهات منصة بوابة البصريات

هذا هو التحويل الرسمي للمشروع من مساعد دردشة إلى **مصنع فيديوهات تعليمي خاص بمحمد سعيد وحده**. المصنع يبني الفيديو من درس منظم، ويحفظ كل مراجعة، ويوقف العمل عند بوابتين بشريتين إلزاميتين: اعتماد السكريبت علميًا، ثم اعتماد الفيديو نهائيًا. لا يوجد أفاتار متحرك، ولا موسيقى، ولا نشر آلي.

المسار الهجين معتمد رسميًا منذ 21 أغسطس 2026: يُنتج HeyGen Digital Twin المقدمة والخاتمة فقط بإجمالي لا يتجاوز 30 ثانية، بينما ينفذ المصنع بقية الفيديو. لأن نصي المقدمة والخاتمة ثابتان، يُنشآن كمقطعين رئيسيين مرة واحدة ثم يعاد استخدامهما في الفيديوهات الـ355؛ لا يعاد استهلاك HeyGen لكل درس إلا إذا تغير النص أو الهوية المعتمدة أو ظهر عيب فني.

## ما يعمل الآن

- لوحة عربية واحدة في `index.html` لإدارة خط الإنتاج.
- خادم Python واحد في `main.py` مع API وقاعدة SQLite وسجل تدقيق.
- استيراد الدروس بصيغة JSON وإنشاء مهام بإصدارات لا يُكتب فوق المعتمد منها.
- توليد السكريبت وخطة المشاهد محليًا عبر Ollama عند توفره.
- مثال علمي مُراجع لتجربة المسار كاملًا من دون انتظار Ollama.
- رندر Storyboard حقيقي بدقة 1920×1080 و25 إطارًا/ثانية باستخدام Pillow وFFmpeg.
- محرك معاينة احترافية مدتها 30 ثانية: سبع شرائح فعلية، رسوم عدسة ومقارنة وسلامة ومصادر، وانتقالات هادئة بخط Noto Sans Arabic موحد.
- عينة أفاتار محلية مدتها 30 ثانية تجمع صورة محمد سعيد وصوته الحقيقي مع حركة كاميرا وموجة صوتية، مع إفصاح ثابت بأنها بلا مزامنة شفاه.
- إعادة رندر مشاهد محددة مع الاحتفاظ ببقية الإطارات.
- صور محمد سعيد الخمس محفوظة كمراجع للهوية والتكوين فقط؛ لا تدخل تلقائيًا في الفيديو ولا تُحرّك.
- الهوية المستخلصة: كحلي وفحمي، زجاج سماوي، عاجي دافئ، حضور أمامي هادئ، وخلفيات علمية/مكتبية.
- قواعد ثابتة: مصرية بسيطة، فكرة ← تفسير ← توصية، بلا موسيقى، المصادر أسفل الفيديو، وإخلاء مسؤولية طبي.
- سياسة تكلفة ثابتة: مقطعا HeyGen الرئيسيان يعاد استخدامهما عبر المنهج كاملًا، والتوليد الديناميكي لكل درس ممنوع افتراضيًا.
- حزمتا HeyGen للمقدمة والخاتمة جاهزتان في `outputs/heygen_master_segments/`، وتحتويان النص، إعدادات Digital Twin، ملف SRT، مرجع المظهر، ومرجع الصوت. حالتهما «جاهزتان للإرسال» وليستا معتمدتين نهائيًا قبل مشاهدة الفيديو الناتج.
- محرك الصوت الرسمي المعتمد في HeyGen هو **Cartesia** مع `Mohamed Saeed – Egyptian Academy Voice` بعد نجاح اختبار تطابق الصوت واللهجة المصرية؛ لا يوجد انتقال تلقائي إلى ElevenLabs V3 أو صوت عام.
- نص المقدمة التنفيذي في الإصدار الثاني المعتمد، ويبدأ بـ«السلام عليكم ورحمة الله وبركاته» ويتضمن «معلومة علمية موثوقة علميًا وببساطة»؛ هذا النص هو المرجع الوحيد للتوليد الجديد.
- شعار **Optics Gate** المرفق من محمد سعيد معتمد اعتمادًا دائمًا منذ 21 أغسطس 2026. نسخة PNG هي أصل الإنتاج الثابت، ونسخة GIF محفوظة كما وردت. أُلغي شعار Optic Master Academy ورمز الدوائر التجريبي والشعار منخفض الدقة المستخرج من HeyGen، ولا يجوز استبدال الشعار الجديد أو إعادة تصميمه دون اعتماد صريح جديد.

## خط الإنتاج

```text
الدرس
  ↓
سكريبت مسودة
  ↓
[SCRIPT_SCIENTIFIC] اعتماد علمي صريح
  ↓
خطة مشاهد بلا أفاتار
  ↓
معاينة MP4
  ↓
[FINAL_VIDEO] اعتماد نهائي صريح
  ↓
جاهز للنشر اليدوي — لا ينشره النظام تلقائيًا
```

## التشغيل السحابي

المتطلبات: Python 3.11+ وFFmpeg. ثبّت Pillow ثم شغّل الفحص والمصنع:

```bash
python3 -m pip install -r requirements.txt
python3 main.py doctor
python3 main.py serve --host 127.0.0.1 --port 8000
```

افتح `http://127.0.0.1:8000`. عند تشغيله على خادم سحابي، ضعه خلف تسجيل دخول وHTTPS؛ لا تكشف Ollama أو SQLite مباشرة للإنترنت.

لإنتاج المثال الحقيقي مباشرة:

```bash
python3 main.py demo --render
```

ينتج ملف MP4 داخل `outputs/<JOB-ID>/v1/storyboard_preview.mp4` ويتوقف قبل الاعتماد النهائي. إضافة `--approve-final` تمثل اعتمادًا صريحًا من سطر الأوامر، ولا تنشر الفيديو.

المعاينة الاحترافية الجديدة لها مسار مستقل حتى لا تختلط بالـStoryboard القديم:

```bash
# يبني المسار البصري الداخلي فقط، ولا يُعد فيديو نهائيًا
python3 tools/render_professional_preview.py

# يبني الفيديو النهائي بعد إضافة تسجيل معتمد مدته 27–30.5 ثانية
python3 tools/render_professional_preview.py --voice data/audio_samples/approved_preview_voice.wav
```

الملف النهائي لا يُنشأ باسم `professional_preview_30s.mp4` إلا عند وجود صوت معتمد. النص المطلوب تسجيله محفوظ في `data/audio_samples/نص_تسجيل_المعاينة_30_ثانية.md`. يمنع المحرك قص تسجيل أطول من 30.5 ثانية أو وضع TTS بديل تلقائيًا.

لتجربة الصورة والصوت الحقيقيين داخل المصنع مباشرة:

```bash
python3 tools/render_avatar_style_sample.py
```

ينتج `outputs/avatar_style_sample/factory_avatar_style_30s.mp4`. هذه عينة تحريك بصري لصورة ثابتة وليست Digital Twin؛ مزامنة الفم والحركة التعبيرية الحقيقية تظل من اختصاص HeyGen أو مزود أفاتار مماثل. لا يستبدل المصنع صوت محمد سعيد تلقائيًا بأي TTS.

## Ollama

النموذج الافتراضي هو `qwen2.5:7b-instruct` ويمكن تغييره:

```bash
MODEL_NAME=qwen2.5:7b-instruct python3 main.py serve
```

Ollama مطلوب فقط لتوليد سكريبت أو مشاهد جديدة. المثال الجاهز والرندر والاعتمادات تعمل من دونه.

## حدود النسخة الحالية

- تم تثبيت خط الأساس للمخطط: 20 بابًا، 40 مقررًا، 80 فصلًا، 355 درسًا/فيديو، 2,485 اعتمادًا، 60 سؤالًا و32 مصدرًا. الموجود داخل الحزمة الآن **درس تجريبي واحد فقط**؛ بقية المنهج تحتاج استيرادًا من المصدر المعتمد.
- الـStoryboard الأول محفوظ للمقارنة فقط. المسار البصري الاحترافي الجديد جاهز، أما ملفه النهائي فينتظر تسجيلًا مطابقًا للنص المعتمد.
- عينة الصوت الأصلية مستخدمة كما هي في عينة الصورة والصوت فقط؛ لم تُستخدم في TTS أو استنساخ صوت، ولا يُفعل الاستنساخ قبل اختبار النطق الطبي واعتمادك.
- إعداد Supabase وn8n موثق في `config/factory.json` لكنه غير متصل بعد لعدم وجود اتصال مصرح وبيانات اعتماد ضمن هذه الحزمة.
- لا يوجد رفع إلى المنصة أو يوتيوب. هذا مقصود للحفاظ على الاعتماد اليدوي.

## الاختبار

```bash
python3 -m unittest discover -s tests -p 'test_*.py' -v
```

الاختبارات تتحقق من: منع الأفـاتار والموسيقى والنشر الآلي، وجود المراجع الخمسة، منع تجاوز الاعتماد العلمي، عدم الكتابة فوق القرار المحفوظ، إنتاج MP4 فعلي، وعقد المعاينة الاحترافية ومدتها ودقتها وخطوطها.
