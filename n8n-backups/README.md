# نسخ احتياطية لـ Workflows بوابة البصريات

تم إنشاؤها تلقائيًا كنسخة احتياطية كاملة من n8n بتاريخ 2026-08-25.

## الملفات
1. `1-بوت-اعتمادات-تليجرام.json` — بوت اعتمادات الفيديو والمحتوى الكامل (27 عقدة)
2. `2-مصنع-السكريبتات.json` — مصنع السكريبتات بـ7 مراحل + توليد الوسائط (70 عقدة)
3. `3-تنبيه-الأعطال.json` — تنبيه تليجرام تلقائي عند أي فشل

## ⚠️ تنبيه أمان
هذه الملفات تحتوي على مفاتيح API فعلية (Supabase, Ollama, HeyGen, Telegram) بشكل ظاهر (Hardcoded).
**لا ترفع هذا المستودع كـ Public** إلا بعد تنظيف المفاتيح، أو خليه Private.

## طريقة الاستعادة
في n8n: Workflows → Import from File → اختار الملف المطلوب.
